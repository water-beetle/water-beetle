# Hi, I'm Dong 👋

I build games and development tools with **Unreal Engine 5 and C++**.
Outside my day job, I work on game systems, procedural worlds, and tools that make development easier.

## Currently building

**Orbital Days** — a space life simulation game in development.

I'm exploring procedural planets, voxel terrain, and the systems that bring everyday life in space together. I share progress, implementation notes, and optimization work in my [development blog](https://water-beetle.github.io/).

## What I work on

- **Game development:** Unreal Engine 5, C++, and Blueprints
- **Procedural geometry:** voxel systems, custom mesh generation, and `FDynamicMesh3`
- **Developer tools:** C#, WPF, and Visual Studio extensions
- **Automation:** Python, PowerShell, CI builds, and asset pipelines

## Tools I use

Unreal Engine · Visual Studio · Rider · Git · GitHub
